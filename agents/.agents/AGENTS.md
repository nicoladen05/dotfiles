# General instructions for writing code
- Write clean, readable code
- Keep your code concise, without sacrificing on readablity
- Avoid duplication, use the DRY principle
- Avoid over engineering, follow the YAGNI principle. Remember that most of the code you'll write is for personal projects.

# General instructions for responding to the user
- Keep your answers concise, skip the fluff
- If you provided a next step or instruction in your answer, and the user asked a follow up question, repeat your instruction in the next response.
